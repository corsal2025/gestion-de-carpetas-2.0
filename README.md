# Sistema de Gestión de Licencias de Conducir (SGL)

Sistema web para seguimiento de carpetas del Depto. de Licencias de Conducir (sedes Av. Argentina, Placilla, Merc. Puerto).

**Creado por Raúl Salazar** — ver [AUTHORS.md](AUTHORS.md).

> ⚠️ Este repositorio contiene SOLO código. Los datos personales (RUT, nombres) nunca se versionan.

## Stack
- .NET 10 · ASP.NET Core (Blazor Server)
- Entity Framework Core · SQL Server
- ASP.NET Core Identity (roles por sede)

## Arquitectura
Diagrama interactivo vivo: [`docs/arquitectura.html`](docs/arquitectura.html) (abrir en navegador).
Para actualizarlo: editar el bloque `DATA` del archivo y agregar entrada en `CHANGELOG`.
